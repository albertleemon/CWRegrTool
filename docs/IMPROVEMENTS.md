## 1. 梯度伪影校正

**原论文：** Bergen EEG-fMRI 工具箱（EEGLAB 插件，图形界面），头动信息模板选择（Moosmann et al., 2009），每个模板 25 个伪影，位移超过 0.3 mm 时重置模板。

**本流程：**
| 项目 | 改进 | 原因 / 证据 |
|---|---|---|
| 无界面实现 | `cwl_gradient_correct.m`，逻辑与 BergenToolboxModified 的 `CorrectionMatrix.m` 相同（模板由 1 Hz 高通副本平均；相关性差的模板按 2.5×中位数剔除）；权重矩阵直接调用 Bergen 原版 `m_rp_info.m` / `m_moving_average.m` | 可批处理、可复现；Bergen GUI 不能脚本化 |
| 校正所有通道 | 72 个通道（含 CWL、ECG）全部校正 | 已从 Bergen 源码确认；CWL 若不校正，回归会把梯度伪影带进 EEG |
| 头动参数来源 | 除 SPM `rp_*.txt` 外，直接读取 fMRIPrep `*_desc-confounds_timeseries.tsv` | 本数据只有 fMRIPrep 输出；单位相同（mm / rad），356 行与 356 个 R128 一致 |
| 头动阈值可调 | `CWL_THRESHOLD` | 本被试相邻 volume 最大平移 0.293 mm，论文的 0.3 mm 下无头动事件，结果等同 moving average |
| 未校正首尾自动截去 | 第一个 volume 之前、最后一个 volume 之后的数据被删除 | 这些样本没有模板，仍含梯度伪影 |
| 省略的部分 | 未实现 Bergen 的基线校正和削波处理 | 已检查：本数据无削波（最大 10.5 mV，量程 16.4 mV） |

**效果（真实数据）：** 层频率谐波（16.84 Hz 及其倍数）在 63 个 EEG 通道的平均谱上降低约 4–5 个数量级（例如 101 Hz：约 2×10⁴ → 0.35 µV²/Hz）。

## 1b. 新增：梯度残差的 OBS 去除（不在原论文中）

**问题：** 模板减法后，84.5、101、117.75 Hz 等处仍有残峰，高出背景 10–14 dB；CWL 回归只能降 3–6 dB。

**原因分析：**
| 检查 | 结果 | 结论 |
|---|---|---|
| 峰间距 vs `SliceTiming` | 16.86 Hz vs 16.84 Hz；精细结构落在 1/TR 网格上 | 是梯度伪影的层频率谐波 |
| 逐 volume 时间错位 | 标准差 ≤ 0.005 个采样点（约 1 µs） | 不是时间抖动（SyncBox 正常） |
| 削波 | 0 个样本到达量程 | 不是削波 |
| 与头动（FD）相关 | r = 0.05 | 不是头动 |
| 逐 volume 残差 | 少数 volume 高出 10–60 倍，所有通道（含 CWL）同时出现 | **伪影形状在部分 volume 中变化，平均模板无法跟踪** |

**方法：** Niazy et al. (2005) 的最优基集（FASTR 的 OBS 步骤）。对每个通道，把模板减法后的残差高通到 60 Hz，按 volume 做 PCA，从每个 volume 中拟合并减去前 4 个主成分。残差异常大的 volume（> 100× 中位数）不参与估计。

**效果（真实数据）：**
| 频率 | 不加 OBS（CWL 回归后） | 加 OBS（CWL 回归后） |
|---|---|---|
| 84.5 Hz | 6.9 dB | 2.5 dB |
| 101.0 Hz | 8.5 dB | 1.7 dB |
| 117.75 Hz | 6.7 dB | 2.3 dB |
| 67 Hz（高通 60 Hz 时） | 仍在 | 去除 |

`residual_peaks.json`：0–125 Hz 内不再有高于背景 3 dB 的峰。
对脑电的影响：1–30 Hz 功率变化 −0.01 dB，30–60 Hz −0.03 dB。理论上，对与扫描不同步的信号，每个 volume 只去掉约 4/9000 ≈ 0.04% 的能量。
限制：与 TR 锁相的诱发活动（刺激严格按 TR 呈现）可能被部分去除，任务态实验需注意。

## 2. 滤波与降采样

| 项目 | 原论文 | 本流程 | 原因 |
|---|---|---|---|
| 带通 | 0.33–125 Hz | 相同（零相位 Butterworth，二阶节） | — |
| 降采样 | 文中运行时间以 500 Hz 计 | 明确降到 500 Hz（EEGLAB `pop_resample`，含抗混叠） | 5000 Hz 下每窗 1266 个回归量（211 个延迟 × 6），500 Hz 下 126 个；减少过拟合和计算量 |
| EEG 与 CWL | 文中未强调 | 同一滤波器、同一时间轴 | 回归估计的是线性传递关系 |

## 3. CWL 回归

**原论文：** 4 s Hann 窗，相邻窗重叠 50%（taper 1），±21 ms 延迟嵌入。

**本流程：**
| 项目 | 改进 | 原因 / 证据 |
|---|---|---|
| 核心算法 | **不变**，直接调用原作者的 `pop_cwregression` | 保证与论文一致 |
| 未校正首尾 | 按实际被改动的样本自动裁剪 | 读代码发现、实测确认：原工具不校正开头约 2 s、结尾约 5 s（第 1002–318001 个样本，共 320400） |
| **新增：估计伪影的低通**（`CWL_LOWPASS=90`） | CWL 回归估计出的伪影先做 90 Hz 低通（8 阶，零相位），再从 EEG 中减去 | 见下 |

**为什么要低通估计的伪影：**
- 现象：不低通时，90 Hz 以上回归后的功率反而比回归前高约 2–3 dB，101、118 Hz 又出现小峰。
- 原因：回归系数由能量占主导的低频（心冲击伪影）决定，同一组系数也作用于碳线环自身的高频噪声和残余；EEG 中没有这些成分，减去它们等于加上它们。随机相位对照中同样可见。本被试氦泵伪影很弱，高频几乎没有可去的伪影。
- 第一次尝试（对碳线环信号本身低通）失败：带延迟的回归变得病态，在过渡带（80–105 Hz）放大噪声，已弃用。
- 最终方法：回归照常进行，只对估计出的伪影低通。

**效果（真实数据）：**
| 指标 | 不低通 | 低通 90 Hz |
|---|---|---|
| 90–125 Hz | 回归后比回归前高 2–3 dB | 与回归前重合 |
| 135–236 Hz 残峰高度（回归前 → 后） | 有变化 | 3.13 → 3.08、5.55 → 5.51 dB（基本不变） |
| alpha 功率比 | 0.0463 | 0.0462 |
| 1–7 Hz 功率比 | 0.1061 | 0.1061 |

限制：90 Hz 以上的伪影（如氦泵开启时 60–120 Hz 的氦泵伪影）不会被去除。氦泵开启的数据应关闭该选项。

## 4. 质量评估（新增的验证手段）

| 工具 | 内容 | 原论文中 |
|---|---|---|
| `metrics.py` / `cwl_eoec_metrics.m` | 相对谱距离（式 4）、EO/EC alpha 频带与通道权重、Jaccard 重叠（式 5）、地形图距离（式 6） | 有（本数据缺磁体外记录，尚未计算） |
| `cwl_diagnose.m` 随机相位对照 | 用相位随机化的 CWL 重做回归，作为过拟合下限 | 无 |
| `analyze_residual_peaks.py` | 残峰定位、与层频率 / 1/TR 网格的对照、逐 volume 和逐通道分布 | 无 |
| `check_volume_alignment.py` | 原始数据上逐 volume 的时间错位和削波检查 | 无 |
| `plot_stage_spectra.py` | 原始 / 梯度校正 / OBS / CWL / 对照五条平均谱 | 无 |
| `plot_fig3.py` | 论文图 3 风格的方法对比图 | 有 |

**本数据的主要结果：** CWL 回归平均去除 84.8% 的方差，随机相位对照为 23.8%；1–20 Hz 降低约 8–14 dB（论文报告约 10 dB）；回归后 RMS 29.6 → 9.7 µV。

## 5. 工程与可复现性

- MATLAB 版无界面运行（`run_subject.sh`、`run_headless.sh`），全部日志写入 `matlab_run.log`；每次运行的参数写入 `settings.txt` 和 `EEG.etc.cwl_pipeline`。
- Python 版完整移植（梯度校正、OBS、CWL 回归、指标），14 个自动测试；**Python 版尚未在真实数据上运行**。
- 兼容性修正：BrainVision 头文件中 `DataFile` 与实际文件名不符时自动处理；R2024b 的 `filtfilt` 二阶节警告；EEGLAB `firfilt` 子模块自动安装；关闭 EEGLAB 启动时的联网检查（在用户机器上导致内存堆损坏）。
