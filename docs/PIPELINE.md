# 流程逻辑说明（先读这个，再跑真实数据）

## 0. 要解决什么问题

同步 EEG–fMRI 的 EEG 里叠加了三类伪影，量级相差很大：

| 伪影 | 来源 | 特点 | 本流程用什么去掉 |
|---|---|---|---|
| 梯度伪影 | MRI 梯度切换 | 幅度极大（可到毫伏级），与扫描严格同步，每个 volume 形状几乎相同 | 模板减法（Bergen / Moosmann 方法） |
| BCG 心冲击伪影 | 心跳带动头和电极在磁场中运动 | 与心跳同步但每次形状不同，非扫描同步 | 碳线环（CWL）回归 |
| 氦泵 / 振动伪影 | 氦压缩机振动传到电极、导线 | 宽频、窄峰，与扫描不同步 | 碳线环（CWL）回归 |

关键想法（van der Meer 等，2016）：BCG 和氦泵伪影的共同本质是**电极/导线在磁场中的微小运动**。碳线环不接触头皮，只会感应到运动，不含脑电。所以可以把 EEG 对 CWL 做回归：能被 CWL 线性解释的部分就是运动伪影，减掉即可，不需要 ECG 的 R 波，也不需要模板。

## 1. 为什么顺序是这样

```
原始 EEG（5000 Hz，所有通道：EEG + ECG + CWL）
  │ 1 梯度伪影校正：对所有通道，包括 CWL
  ▼
  │ 2 截掉校正范围以外的首尾
  │ 3 0.33–125 Hz 带通（所有通道同一滤波器）→ 降采样到 500 Hz
  ▼
  │ 4 CWL 回归：只作用于 EEG 通道
  ▼
伪影校正后的 EEG ── 5 与磁体外 EEG 对比（可选）
```

1. **梯度校正必须先做，而且 CWL 也要做。** 环路对梯度场非常敏感，若 CWL 里还留着梯度伪影，回归会把它当“运动”注入 EEG。
2. **梯度校正在高采样率（5000 Hz）上做。** 梯度伪影含高频成分，降采样会让模板对不齐。
3. **用于回归的 EEG 与 CWL 必须同一个滤波器、同一个时间轴。** 回归估计的是线性传递关系，滤波不一致会破坏它。
4. **降采样到 500 Hz 再回归。** 每个 CWL 取 ±21 ms 的延迟，5000 Hz 下每个窗约 1266 个回归量，500 Hz 下约 126 个：更快、更不易过拟合；论文也是 500 Hz。
5. **CWL 回归只作用于 EEG 通道**，不作用于 ECG、CWL 以及未用的 65/66 通道。

## 2. 每一步的算法

### 步骤 1：梯度伪影（模板减法）

对每个通道、每个 volume i：
1. 取该 volume 的数据段 A_i（从 R128 标记起，长 = 1 个 TR）。
2. 从若干其他 volume 的段求平均得模板，再 A_i − 模板。
3. **选哪些 volume 当模板**由权重矩阵 W 决定：
   - 无头动参数：moving average，取时间上最近的 k=25 个 volume（Allen 2000）。
   - 有头动参数：`rp_info`（Moosmann 2009）。头一动，梯度伪影形状就变，所以**不跨越头动事件**取模板：两个 volume 之间若出现超过阈值（论文 0.3 mm 的帧间平移位移）的运动，就不让它们互为模板；运动本身那一帧也不当模板。
4. 模板由 1 Hz 高通后的副本平均得到，避免慢漂移污染模板；与其余模板相关性很差的段（相异度 > 2.5×中位数）被剔除。
5. 校正范围（第一个标记到最后一个标记+TR）以外的数据没有模板，仍含梯度伪影，必须剪掉。

### 步骤 3：滤波 + 降采样
零相位带通 0.33–125 Hz（EEG、ECG、CWL 全部一致），然后整数倍降采样 5000→500 Hz。

### 步骤 4：CWL 回归（论文的核心）

对每个 4 s 的 Hann 窗（相邻窗重叠 50%，权重和为 1）：
1. 把 6 个 CWL 各自在 ±21 ms（500 Hz 下 ±10 个样本）的所有延迟堆起来，得到 126 个回归量。延迟让回归同时拟合“环路到电极的时间差”和“传递函数”。
2. 对每个 EEG 通道，把“加窗后的 EEG”对“加窗后的回归量”做最小二乘。
3. 拟合出的部分 = 该窗内的运动伪影。窗间叠加后除以权重和，得到整条伪影轨迹，从 EEG 中减去。
4. 窗口很短（4 s），所以每个窗都自适应：头姿变了、氦泵与 BCG 的比例变了，系数就跟着变；而且只用当前窗的数据，不需要“前面 10–20 s 无运动”的模板。

### 步骤 5：评估（与磁体外同被试 EEG 对比）
- **相对谱距离**：校正后谱与磁体外谱的相对距离（%），越小越好。
- **EO/EC 频带**：用磁体外数据按“闭眼−睁眼”的 alpha 增幅确定频带、通道和权重。
- **Jaccard 重叠**：扫描内与磁体外的 alpha 睁闭眼“面积”交并比，越大越好。
- **地形图相对距离**：各通道 alpha 增幅的空间分布与磁体外的差异。
- **BOLD 相关（论文第三部分）未包含**，本流程止于 EEG 预处理。

## 4. 用真实数据跑之前先确认

1. `R128` 标记数 = 实际 EPI volume 数（含 dummy），相邻间隔 = TR。
2. 若用头动参数：`rp_*.txt` 对应同一 run 的后 N 个 volume（前面被去掉的视为 dummy）。
3. 通道：CWL = `CW1`–`CW6`，ECG = `ECG`，65/66 排除。
4. 记录在最后一个 volume 之后至少还有 1 个 TR 的数据，否则要先去掉最后一个标记。
5. 内存：72 通道 × 5 分钟 × 5000 Hz ≈ 1.5 M 样本/通道，双精度约 0.9 GB，运算中会有几份拷贝，建议 ≥ 16 GB 内存。
